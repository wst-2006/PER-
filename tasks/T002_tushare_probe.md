# T002 Tushare 权限与历史深度探测

**目的**：实测这个账号每个接口能否调用、能回溯到哪一年、财务数据是否带实际公告日和修订版本。新系统的数据设计取决于这份结果。

**前置**：T001 通过；`.env` 中已有 `TUSHARE_TOKEN`。

## 步骤

```powershell
python scripts/tushare_probe.py
```

约 90 次调用，正常几分钟内完成。被限流时脚本会自动等待，不要中断，也不要改脚本。

## 提交

- `results/T002/probe.json`、`results/T002/run_meta.json`、`results/T002/REPORT.md`
- 提交信息：`T002: tushare 权限探测结果`

## 说明

- 接口调用失败或返回空表是**有效结果**，照实记录即可，不算任务失败。
- 标为 `uncertain` 的接口是设计方不确定名称或权限的，失败是预期内的。
- 只有脚本本身崩溃、或交易日历取不到，才算任务失败。
- `probe.json` 只含行数、字段名、日期范围等元数据。提交前请确认里面没有 token。
