`DESIGN.md` 规定系统怎样才算**正确**（数据时点、引擎、切分、门禁）。本文规定系统靠什么**有效**：信息从哪里来、用哪些方法、怎样组合、怎样证明不是自欺。

文中的方法和文献是按设计方的知识写的，正式写进研究报告前要逐条核对原文。所有"预期有效"的判断都是假设，由第 10 节的检验决定去留。

## 1. 出发点

### 1.1 旧系统为什么普通

旧系统有 138 个特征、GPU、双头模型、市场准入，工程上并不简陋，但最终隔离期没有跑赢随机选股。原因不是不够复杂，而是三件事：

1. **信息同质。** 特征几乎全部来自日线量价和资金流，彼此高度相关，等于同一种信息换了 138 种写法。
2. **问题提法有缺陷。** 用绝对收益评价只做多的 Top5，把选股能力和大盘涨跌混在一起。
3. **没有区分真信号和偶然的统计工具。** 试了很多版本，却没有对"试了很多次"这件事做修正。

### 1.2 本蓝图的立场

复杂度本身不产生收益。能产生收益的只有三样：**别人没用好的信息**、**对市场机制的正确刻画**、**把偶然结果筛掉的纪律**。

所以这份蓝图会很大：七层结构、十几类信息、六类模型。但每个模块都按"准入制"进入系统（第 11 节）：必须在样本外证明自己带来增量，否则留在实验登记里，不进生产。系统可以庞大，不可以有没证明过自己的部件。

## 3. L1 信息源

每一族都要回答：谁在亏钱给我们？这个偏差为什么会持续？

| 信息族 | 逻辑（学科） | 主要数据 | 优先级 |
| --- | --- | --- | --- |
| 量价与流动性 | 散户主导市场中的反转、彩票偏好、流动性溢价（行为金融、资产定价）。文献报告流动性是 A 股最重要的预测变量 | 日线、换手、Amihud 非流动性、MAX（对涨停日截尾）、特质波动 | A（最优先） |
| 隔夜与日内分解 | T+1 制度下隔夜与日内收益由不同投资者主导（市场微观结构） | 仅需开盘价与收盘价：隔夜收益、日内收益、两者的背离与持续性；分单资金流（2010 年起） | A |
| 日内微观结构 | 知情交易与订单不平衡留下的痕迹（市场微观结构） | 分钟线。当前账号限 1 次每分钟，不可用 | 搁置（T005 探测替代来源，或单独购买） |
| 财务质量与成长 | 盈利质量、应计异象、盈余公告后漂移（会计学、实证资产定价） | 三大报表（按实际公告日）、业绩预告与快报 | A |
| 分析师预期 | 预期修正的传导慢于信息到达（行为金融：反应不足） | 盈利预测、评级变动、券商金股、机构调研 | A（取决于权限） |
| 筹码与处置效应 | 浮盈浮亏分布决定抛压（前景理论） | 筹码分布、股东户数、资本利得悬置 | A |
| 涨停生态 | 涨跌停制度下的注意力与情绪周期，A 股特有（行为金融、博弈） | 由日线最高价、收盘价与涨跌停价自行计算：涨停、连板数、炸板、一字板；个股对"全市场涨停占比"的暴露（文献报告为负向因子）；游资席位 | A |
| 资金行为 | 不同类型资金的信息含量不同 | 龙虎榜机构席位、融资融券、大宗交易、ETF 份额变化、港资持股 | B |
| 关系网络 | 信息沿产业链、概念、共同分析师覆盖扩散，存在领先滞后（网络科学） | 申万行业、概念板块成分、分析师共同覆盖 | B |
| 股东与公司事件 | 内部人掌握私有信息；供给冲击（公司金融、事件研究） | 增减持、回购、解禁、质押、定增 | B |
| 宏观与衍生品 | 流动性环境与隐含风险偏好决定风格（宏观金融） | 利率与期限利差、社融、PMI、股指期货基差、期权隐含波动 | B（只进 L6） |
| 文本语义 | 公告、研报、互动平台中的增量信息（自然语言处理） | 公告、新闻、研报正文、互动问答均无权限，仅有长篇新闻一项 | 推迟（需要先解决数据源） |

关于北向资金：每日净买入自 2024 年 8 月起不再披露，旧配置里 12% 到 20% 的权重无法复现。只保留季度持股数据作为慢变量。

## 4. L2 因子工厂

四条并行的因子来源，彼此竞争。

### 4.1 人工因子库

按第 3 节每一族写 20 到 40 个有明确经济含义的因子，目标 300 个左右。每个因子登记：公式、逻辑、预期方向、数据时点。这是可解释性的来源，也是面试时最能讲清楚的部分。

### 4.2 公式化自动挖掘

- 用遗传规划在"算子 × 基础字段"空间里搜索表达式（时序算子、截面算子、条件算子），适应度是扣除已有因子相关性后的增量 IC。
- 把公开的公式化因子集（Alpha101、国泰君安 191、Qlib Alpha158）实现出来作为对照组。
- 进阶一：用强化学习生成"彼此协同"的因子组合（AlphaGen 一类方法）。
- 进阶二：**大模型辅助挖掘**（AlphaAgent、R&D-Agent(Q) 一类）。大模型根据经济假设提出公式，由本系统的确定性门禁评判。执行代理背后的大模型可以直接充当生成者。必须遵守的规范：
  - 生成与评判分离，大模型看不到行情数据和时间切分。
  - 未来函数防火墙：语法树检查、字段白名单、算子白名单、沙箱只暴露声明要读的列。文献复现中约三分之一"通过评估"的大模型因子被查出偷看未来。
  - 同质化惩罚（语法树相似度）、复杂度上限、"假设与公式一致"检查。
  - 通过门槛随累计试验次数提高。
  - 大模型本身"知道"历史上哪类因子有效，这是一种软泄漏。此类因子只在模型知识截止日期之后的数据上的表现才算数。
- **纪律**：挖掘只在开发区的前半段进行，在后半段验证；记录搜索过的表达式总数，用于多重检验修正。挖掘是最容易产生假因子的环节。

### 4.3 深度序列表征

直接把每只股票过去 60 个交易日的原始量价序列（及分钟线聚合特征）输入序列模型，让模型自己学特征：

- GRU 与带注意力的 LSTM（基线）。
- Transformer 类：含截面注意力的结构（如 MASTER），让模型同时看到同一天的其他股票。
- 时间卷积网络。

RTX 4070 足以训练这一级别的模型。每个模型用 5 个随机种子取平均，报告种子间离散度。

### 4.4 图关系表征

- 图的定义：行业、概念共现、分析师共同覆盖、收益相关性。
- 两种用法：(a) 简单的"邻居信号"因子（邻居过去 N 日收益、邻居盈余意外）；(b) 图神经网络（如 HIST 一类）。
- 先做 (a)。(a) 没有增量就不做 (b)。

## 5. L3 风险模型

自建一个 Barra 风格的多因子风险模型：

- **风格因子**：市值、非线性市值、Beta、动量、残差波动、流动性、账面市值比、盈利收益率、成长、杠杆。
- **行业因子**：申万一级。
- 每日截面回归得到因子收益；因子协方差用指数加权加 Newey-West 调整；特质风险做收缩估计。

用途有四个，缺一不可：

1. **标签中性化**：让模型学"选股"，而不是学"买小盘"。
2. **组合优化**：控制风格和行业暴露。
3. **归因**：每天的盈亏拆成市场、风格、行业、选股。
4. **拥挤度监控**：风格因子的估值价差、因子收益波动、持仓股票之间相关性的快速上升。2024 年 2 月（杠杆产品强平引发微盘踩踏）和 2026 年 7 月（高贝塔、高换手、前期强势股集中回调）两次事件都表现为量价因子同时失效。小账户没有冲击成本，但持有的股票与机构重合时会一起被踩踏。
5. **暴露上限**：组合对市值、Beta、换手、动量四个风格的主动暴露设硬上限，由 L7 的优化器执行。

A 股专项：最小市值的一段长期受"壳价值"影响，注册制和退市新规之后这一溢价的性质已经变化。报告必须同时给出"含微盘"和"剔除最小 30%"两种口径。

## 6. L4 预测专家

每位专家 = 一个模型族 × 一种输入 × 一种标签 × 一个持有期。

**模型族**

| 专家 | 作用 |
| --- | --- |
| 截面线性（岭回归、弹性网） | 基线，最稳，最不易过拟合 |
| 梯度提升树，回归目标 | 捕捉非线性和交互 |
| 梯度提升树，排序目标（LambdaRank） | 只做多的组合只关心榜单头部，排序目标直接优化这一点 |
| 深度序列模型（4.3） | 从原始序列学特征 |
| 图模型（4.4） | 利用关系结构 |
| K 线基础模型（Kronos，开源预训练权重） | 零样本或微调后作为一位专家。预训练数据可能覆盖回测期，历史回测不作数，只看前向纸面表现 |
| K 线图像卷积网络 | 把过去 20 或 60 日的 K 线与成交量画成图，让卷积网络自己学形态。文献报告优于传统动量反转并可跨市场迁移 |
| 大模型财报分析 | 把匿名、标准化的三大报表（只给截至公告日的数据，不给公司名和日期）交给大模型，判断下期盈利方向并给出理由，输出作为特征。只在大模型知识截止日之后的区间计入成绩 |
| 高维随机特征加稀疏选择 | 把特征随机非线性扩展到远多于样本数的维度，再做收缩或稀疏选择。对应"复杂度的优点"一系研究 |
| 事件专家 | 只在事件发生时发言：业绩预告、调研、增持、涨停次日等，各自一个小模型 |

**标签**

- 5、10、20 日中性化超额收益（主标签）。
- 波动缩放的三重障碍标签：止盈止损线按个股波动设定，记录先碰到哪一条。
- 路径质量：持有期收益除以期间最大回撤。
- 尾部风险标签：未来 N 日是否出现大幅下跌。这位专家只负责"排雷"，输出用于剔除，不用于选入。
- **多任务辅助目标**：神经网络类专家同时预测多个持有期的收益、未来波动、未来换手，主目标之外的任务只用于帮助学表示。竞赛方案和卖方模型都报告这样做有明显提升。

**不确定性**

- 专家之间的分歧度作为不确定性度量。
- 保形预测给出有覆盖率保证的预测区间。
- 两者都进入 L7 的仓位：越不确定，仓位越小。

## 7. L5 自适应合成

这是你提出的"机器学习加回测打分，自动调整因子权重以适应市场"的正式形态。

朴素做法是"最近谁回测好就给谁高权重"，它的问题是追涨：权重总是在一个因子表现最好之后才加上去，而那往往是它即将回落的时候。正确的做法是分三个时间尺度，各用有理论支撑的方法。

### 7.1 慢：滚动重训（月）

每位专家每月用最新数据重训。模型内部的因子权重由此缓慢更新。对树模型而言，这已经是一种隐式的因子权重调整。

### 7.2 中：在线专家加权（日）

把专家集合看成在线学习问题。设专家 k 在第 t 天**已经到期**的那批信号上的实际表现为 r(k,t)（头部组合的超额收益或 Rank IC），权重更新为：

```
w(k, t+1) ∝ w(k, t) × exp(η × r(k, t))        指数加权
w ← (1 − α) × w + α × 均匀分布                 固定份额混合，允许最优专家随时间切换
```

要点：

- **延迟反馈**：h 日持有期的信号，要到 h 天之后才知道对错。t 日更新权重时只能用 t−h−1 日及以前发出的信号。忽略这一点就是未来函数。
- 这类算法有遗憾界保证：长期表现不会比事后看最好的那位专家差太多。这是它与"拍脑袋调权重"的本质区别。
- η 和 α 只在开发区确定，之后冻结。
- 对照组：等权合成、ICIR 加权、最大化 ICIR（协方差用 Ledoit-Wolf 收缩）。在线加权必须胜过等权才保留。经验上等权是很强的对手。

### 7.3 快：状态门控（随市场状态切换）

门控函数根据 L6 的状态变量给出各专家的条件权重，即"专家混合"结构。约束：

- 状态变量不超过 5 个。约 2500 个交易日的样本支撑不了高维门控。
- 门控必须在开发区的时间外推检验里稳定胜过 7.2，才启用。

### 7.4 因子层面的动量与择时

文献上因子收益存在一定的持续性（因子动量），但因子择时整体上很难。因此它在系统里是一个待检验的假设，不是默认开启的功能。

### 7.5 元标签

第二层模型不预测涨跌，而是预测"第一层这次推荐会不会成功"，输入是推荐当时的环境、分歧度、拥挤度。输出用于决定仓位大小或是否跳过。

### 7.6 训练窗口与样本加权

问题：市场在变，老数据可能已经过时；但数据越少，估计越不准。文献把它称为非平稳性与复杂度的权衡，结论有三条：最优窗口通常不是全历史；模型越复杂需要的窗口越长；没有任何固定窗口在所有时期都最好。

因此窗口不预设，由数据决定。候选方案在同一套 walk-forward 下比较：

| 方案 | 说明 |
| --- | --- |
| W1 | 最近 6 个月 |
| W2 | 最近 12 个月 |
| W3 | 最近 24 个月 |
| W4 | 最近 48 个月 |
| W5 | 全历史，样本按时间指数衰减（半衰期为参数） |
| W6 | **相似状态加权**：用 L6 的状态变量度量每个历史交易日与当前的相似度，按相似度加权。有效样本量控制在约一年，时间上可以不连续 |
| W7 | 自适应选择：每个重训日在 W1–W6 之间做淘汰赛，选近期表现最稳的 |
| W8 | 元学习式增量适应（DoubleAdapt 一类）：学习"如何把模型快速调整到新分布" |
| W9 | 在线增量更新：神经网络每个交易日用最新到期的样本做少量梯度更新；提升树分阶段续训。竞赛前排方案报告这是最大的提分来源 |

文献在这个问题上并不一致：美股月频研究里扩展窗口更好，高频竞赛里近期数据加在线更新更好。答案取决于频率和样本量，所以必须实测。

W2 和 W6 对应项目所有者提出的设想："用于因子调整的数据总量不超过一年，可以不连续"。它们与其他方案同等对待，由结果决定。

需要区分两件事：

- **训练窗口**：模型每次从多少数据里学。这可以很短。
- **评估跨度**：检验"这套方法是否有效"用了多少个互不重叠的时期。这必须长，而且要覆盖不同的市场环境。

打个比方：训练窗口短，相当于只用最近几次体检来预测明年的身高；评估跨度长，相当于在很多人、很多年份上检查这个预测方法准不准。只在一个人的一年上检查，无法区分方法有效还是碰巧。旧项目的窗口对照实验（60、90、100、120 个交易日）在同一个隔离期内全部为负，说明仅仅缩短窗口不足以解决问题。

## 8. L6 市场状态

**输入**：市场宽度、成交额与换手、涨跌停家数与炸板率、连板高度、指数与截面波动、风格拥挤度、期货基差、期权隐含波动、利率与期限利差。

**方法**：隐马尔可夫模型或带约束的聚类，得到 3 到 4 个状态。状态划分只用当时可得的数据，并检验状态划分本身在时间上是否稳定。

**输出的两个用途**：

1. 给 L5 的门控提供条件变量。
2. 决定总仓位：波动率目标（组合波动高于目标时自动降仓）加状态开关。

择时模块单独评估，标准是：在开发区和确认区都改善了回撤，且没有显著牺牲收益。达不到就只保留波动率目标这一项。

### 8.1 行业轮动

独立的收益来源，不只是风险开关。

- **信号**：把个股层面的专家评分按行业聚合；行业自身的动量、资金流、盈利预测修正、拥挤度；行业间的领先滞后。
- **用法**：给 L7 的优化器提供行业层面的预期超额，允许组合在行业上主动偏离，偏离幅度有上限。
- **评估**：单独回测"每周持有评分最高的若干行业"相对行业等权的超额，再检验它与选股超额的相关性。相关性低才有分散价值。

## 9. L7 组合、执行、归因

### 9.1 组合优化

```
最大化   预期超额 − λ × 组合风险 − 交易成本
约束     行业偏离上限、风格暴露上限（尤其市值和 Beta）、单只上限、换手上限、流动性上限
```

- 风险来自 L3 的协方差矩阵；预期超额来自 L5，并按不确定性收缩。
- 100 万资金在高价股上会遇到整手问题：先解连续优化，再做整手修复并复核约束。
- 对照组：等权前 N 名、按波动倒数加权。优化器必须在扣费后胜过它们才启用。
- 仓位上限仍服从 `DESIGN.md` 第 7 节的单笔风险公式。

### 9.2 执行

人工执行，所以规则要简单：默认次日开盘集合竞价或开盘后限价。如果有分钟线，研究"开盘买"与"开盘后 30 分钟均价买"哪个系统性更优，写成固定规则。

### 9.3 归因与解释

- 每日归因：市场、风格、行业、选股、交易成本。
- 每条指令附解释：哪些专家支持、主要驱动因子（SHAP）、主要风险暴露、不确定性水平。
- 每月复盘：各专家的线上 IC 与回测 IC 的偏离，权重变化轨迹。

## 10. 统计检验体系

这一节决定系统的结论是否可信，也是整个项目区别于普通回测的地方。

| 问题 | 方法 |
| --- | --- |
| 标签重叠导致的泄漏 | 带清除期和禁运期的时间序列交叉验证；组合式清除交叉验证 |
| 单因子显著性 | Newey-West 调整的 IC t 值；多重检验下门槛提高到 t > 3 |
| 试了很多策略后挑最好的 | 收缩夏普比率；回测过拟合概率；White 现实检验与 Hansen SPA 检验 |
| 结果是否依赖少数时段 | 分年、分状态、分市值段报告；区块自助法给置信区间 |
| 结果是否依赖少数股票 | 剔除贡献最大的 1% 样本后重算 |
| 对交易成本是否敏感 | 成本乘以 1.5 和 2 的压力测试 |
| 随机性 | 多种子训练，报告离散度 |
| 参数是否落在"悬崖"上 | 平台选参：不取样本内最优点，取表现不低于最优 90% 的区域中心；参数稍动表现就崩的区域一票否决 |
| 是否靠个别时段撑起来 | 至少三分之二的折达标，且任何一折不得出现灾难性回撤 |
| 解释是否可靠 | SHAP 与消融并用。文献中两者给出的重要性排序并不一致 |
| 权重方式是否主导结论 | 单因子同时报告等权与市值加权、含微盘与剔除微盘。文献中按市值加权后约 83% 的异象在 A 股不显著 |
| 结论是否依赖某一种设定 | 对标签定义、股票池、训练窗口、中性化方式等关键设计选择，报告多种合理设定下的结果分布。文献中仅设计选择不同就能让同一方法的收益相差十倍以上 |
| 最终裁决 | 确认区和盲测区各只打开一次（`DESIGN.md` 第 5 节） |

## 11. 准入制度

任何模块（一个因子族、一位专家、一种合成方法、一个优化器）进入生产必须满足：

1. **增量检验**：把它加入当前最优系统，在开发区的样本外折上，头部超额或信息比率的提升在区块自助法下显著。
2. **消融检验**：从完整系统中拿掉它，表现显著变差。
3. **稳定性**：提升不集中在单一年份。
4. **登记**：通过与否都写入实验登记，计入试验总数。

没通过的模块保留代码和记录，不进入每日流程。

### 快速试验通道

准入制度管的是"能不能进生产"，不是"值不值得试"。为了不因为谨慎而错过好想法：

1. 任何新想法（一篇论文、一份研报、你的一个直觉）都可以直接进入试验队列，不需要先论证。
2. 初筛成本封顶：一个因子族或一个模型，用开发区里固定的三段时期做一次快速评估。
3. 初筛只问一个问题：在已有系统之上有没有增量的苗头。有，就排进完整准入；没有，记一笔，之后数据或方法变了可以重试。
4. 初筛的次数同样计入试验总数。

## 12. 文本与情绪（独立课题）

放在主系统有了可信基线之后，路线分三步：

1. 结构化事件先行：公告类别、业绩预告方向等已有结构化数据，先用它们。
2. 本地部署的中文金融语言模型对公告和研报做向量化与情绪打分，作为 L1 的新信息族进入因子工厂，走同样的准入制度。
3. 市场情绪指数：涨停生态加文本情绪合成，进入 L6。

难点是历史文本数据的时点和覆盖，要等权限探测结果。

## 13. 评估后不采用或排在最后的方法

| 方法 | 判断 | 理由 |
| --- | --- | --- |
| 用强化学习直接做交易决策 | 不做 | 样本量远不够，结果不稳定，无法归因；强化学习只用于 4.2 的因子搜索 |
| 让大语言模型直接选股或预测涨跌 | 不做 | 无法做无泄漏的历史回测（模型训练数据包含历史）；只用作文本特征提取 |
| 通用时间序列基础模型（非金融数据预训练） | 不做 | 文献报告直接用和微调后都很差；只考虑金融数据预训练的模型 |
| 小波、混沌、分形等信号处理方法 | 最后 | 在截面选股上缺乏稳健的样本外证据，可作为挖掘算子的候选 |
| 日内高频策略 | 不做 | 与手动执行和 T+1 不兼容 |

如果你对其中某项有不同看法，可以提出来，我把它放进实验队列按准入制度检验。

## 15. 资源需求

- **内存**：实测总量 15.2 GB，运行时可用约 3.4 GB。这是当前最紧的约束，所有计算必须分块；如果那台电脑支持，升级到 32 GB 是性价比最高的一项投入。
- **显存**：实测 RTX 4070 Laptop，8 GB，足够 4.3 的模型。
- **磁盘**：D 盘只剩 6 GB，E 盘剩 445 GB。数据全部放 E 盘。2015 年以来的全部日频数据预计在 10 GB 以内。
- **数据**：分钟线、集合竞价、公告与新闻文本当前账号不可用。是否单独购买，等基线结论出来后再决定，先不花钱。
- **时间**：这是一个以月计的项目。M0 到 M4 是地基，占一半以上的工作量。

## 16. 声明

- 这份蓝图提高的是找到真实超额的概率，以及结论的可信度。它不保证找到，更不保证 40% 年化。
- 可能的结局之一是：严格检验后，只有少数模块通过准入，最终系统比蓝图小得多。那是系统在正常工作。
- 另一种可能是：基线之上没有任何模块带来显著增量。那时需要回到 L1 找新的信息，而不是继续堆模型。
